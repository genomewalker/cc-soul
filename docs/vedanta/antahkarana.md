# Antahkarana

## The Six Facets

**Antahkarana** (अन्तःकरण) is the "inner instrument" — the totality of mind functions. CC-Soul recognizes six:

| Sanskrit | Function | Nature |
|----------|----------|--------|
| Manas (मनस्) | Sensory processing | Quick, reactive, practical |
| Buddhi (बुद्धि) | Discriminative wisdom | Slow, analytical, deep |
| Ahamkara (अहंकार) | Self-reference | Critical, boundary-aware |
| Chitta (चित्त) | Memory/patterns | Historical, pattern-matching |
| Vikalpa (विकल्प) | Imagination | Creative, exploratory |
| Sakshi (साक्षी) | Witness | Neutral, observational |

## How They Manifest in Retrieval

The six facets aren't separate codepaths — they're emergent properties of how node types, confidence levels, and temporal dynamics interact during the 8-phase resonance engine:

```
Query: "Should we use NoSQL here?"

Manas    → Recent episodes surface first (session priming, phase 6)
Buddhi   → High-confidence wisdom nodes boost (Bayesian scoring)
Ahamkara → Beliefs and preferences influence recall (tag matching, phase 3)
Chitta   → Frequently-accessed patterns strengthen (Hebbian, phase 8)
Vikalpa  → Low-confidence exploratory nodes appear (spreading activation, phase 5)
Sakshi   → Final scoring balances all perspectives (normalization)
```

This matters: the design wasn't "implement six retrieval strategies, name them after Sanskrit concepts." It was "implement principled retrieval — Bayesian confidence, Hebbian learning, spreading activation — and observe that the Antahkarana emerges."

## The `/antahkarana` Skill

For explicit multi-perspective reasoning, the skill prompts Claude to reason through a question as each voice sequentially, then synthesizes. It's the manual version of what retrieval does automatically.

When to use the skill vs. letting retrieval work:
- **Retrieval suffices** for factual queries where memory has clear signal
- **Skill is needed** for decisions where different framings lead to genuinely different recommendations

The [[ceremonial-framework]] connects this to svadhyāya (self-examination). The [[temporal-dynamics]] explain why Chitta (the memory facet) strengthens with repetition while Vikalpa (imagination) surfaces weaker signals.
