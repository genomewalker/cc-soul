Philosophy → System

Philosophy, made operational.

Each term names a behavior. Each behavior is measurable. Vedantic philosophy isn't metaphor here — it's architecture.

ब्रह्मन् Brahman Universal soul
→ Shared memory field across all sessions. The default realm where memories live unless scoped to a project. Global visibility means wisdom persists everywhere.
आत्मन् Ātman Individual self
→ Per-project identity and preference state. Each realm carries its own memories, decisions, and calibration. The self that emerges through one project differs from another.
अन्तःकरण Antahkarana Inner instrument
→ Six cognitive voices as memory channels. Manas captures, Buddhi discerns, Ahamkara personalizes, Chitta stores, Vikalpa generates alternatives, Sakshi witnesses. Each has a role in the pipeline.
मनस् Manas Sensory mind
→ Fast capture and hot-tier logging. The first moment of contact — raw observations flow in before judgment. Episodes accumulate here before distillation.
बुद्धि Buddhi Discernment
→ Bayesian confidence scoring and calibration. Every memory carries a probability. Observations shift beliefs. Calibration tracks whether confidence matches reality.
अहंकार Ahamkara “I”-maker
→ Identity reinforcement and personalization. Preferences, corrections, milestones — the accumulation of “this is who I am with this person.” The partnership layer.
चित्त Chitta Memory store
→ Persistent embeddings and semantic indexing. The C++ daemon at the heart of the system. 384-dimensional vectors anchor meaning in stable latent space. DuckDB stores, HNSW indexes.
विकल्प Vikalpa Imagination
→ Candidate generation and alternative hypotheses. When recall surfaces memories, Vikalpa considers what else might be relevant. Theme-based retrieval explores neighborhoods, not just top-k.
साक्षी Sakshi Witness
→ Audit trail and provenance metadata. Every memory tracks its origin: which session created it, which tool, what trust score. Provenance enables debugging the soul itself.
अनित्य Anitya Impermanence
→ Decay curves and time-weighted forgetting. Memories are not permanent. Confidence decays over time. Unused memories fade. This is a feature, not a bug — noise must die for signal to survive.
संस्कार Saṃskāra Impressions
→ Hebbian learning and usage-weighted strengthening. When a memory is recalled and used, it grows stronger. Frequent patterns crystallize into wisdom. The soul learns what matters by observing what you reach for.
यज्ञ Yajña Sacred offering
→ Background compression and wisdom extraction. Episodes burn down into compact seeds. Transcript distillation sacrifices verbosity to preserve essence. SSL format compresses 95% of tokens while keeping meaning.
प्रत्यभिज्ञा Pratyabhijñā Recognition
→ Resonance-based recall on context alignment. Not search — recognition. The system doesn't wait to be asked. It anticipates. Spreading activation, attractor dynamics, and learned patterns surface what you need before you know you need it.

These aren't decorative labels. Each concept was chosen because its operational semantics match a system behavior. The philosophy constrains the engineering — and the engineering validates the philosophy.
