What is the constellation?

Each node is a semantic direction — a unit vector in the HDC embedding space that represents a principal axis of meaning, extracted via SVD from the token embedding matrices of open-weight language models. Directions agreed on by multiple model families carry higher consensus and are seeded first into the codebook.

When chitta stores a memory, its tokens are projected onto the nearest codebook directions to form a binary hypervector. Recall queries follow the same path — the Hamming distance between hypervectors is what makes "CRISPR" find "endonuclease" without keyword overlap. The constellation is the coordinate system that makes this possible before any memories exist.
