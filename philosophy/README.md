# cc-soul Philosophy

This directory contains the design rationale for cc-soul as interconnected claims. Each file presents a single assertion with supporting reasoning, practical implications, and links to related principles.

## Organization

Claims are organized by domain but cross-link freely:

- **Vedantic Foundations** - Sanskrit concepts mapping to system architecture
- **Memory Architecture** - Why we store what we store, how we store it
- **Retrieval Philosophy** - How memories surface at the right moment
- **Learning Mechanisms** - How the system adapts to the user
- **Processing Model** - Background operations and lifecycle
- **Integration Design** - How cc-soul fits into Claude Code

## Claim Structure

Each claim follows:
1. **Core assertion** (the filename)
2. **Mechanism** - How it works
3. **Implications** - Design consequences
4. **Trade-offs** - What we sacrifice
5. **Related claims** - Cross-references
