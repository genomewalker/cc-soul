# The Ceremonial Framework

Three Sanskrit concepts shape how cc-soul's deliberate rituals work. Each corresponds to a skill.

## Yajña (यज्ञ) — Sacred Transformation

Yajña is the ceremonial fire into which one pours offerings to transform them. The offering is consumed; something purified emerges.

**Two forms:**

**`/yajña` skill** — Autonomous development ritual. Three roles:
- *Hotṛ* (invoker) — Research and reconnaissance
- *Adhvaryu* (executor) — Implementation
- *Udgātṛ* (chanter) — Testing and validation

The loop runs until the task is complete. Each role contributes its expertise; the ceremony produces working software.

**`/epsilon-yajna` skill** — Compression ceremony:
- Verbose memories are the offering
- SSL (Soul Semantic Language) format is what emerges
- The epiplexity score (ε) measures whether transformation preserved meaning
- Verbosity is consumed; distilled wisdom remains

```
Before: "When building the authentication system, we discovered that JWT
         tokens should be validated using RS256..."
After:  [auth] JWT→validate→RS256+rotate_key→90d
```

## Svadhyāya (स्वाध्याय) — Self-Study

Svadhyāya means turning awareness inward. The `/introspect` skill implements this as structured self-examination through five lenses — which map to the [[antahkarana]] voices:

1. **Vedana** (sensation) — Where is friction?
2. **Jñāna** (knowledge) — Am I applying stored wisdom?
3. **Darśana** (vision) — Do actions align with preferences?
4. **Vichāra** (inquiry) — What patterns recur?
5. **Prajñā** (wisdom) — What has truly been learned?

The lenses aren't separate from the [[antahkarana]] — they're the same cognitive structure applied reflectively rather than reactively.

## Pratyabhijñā (प्रत्यभिज्ञा) — Recognition

Pratyabhijñā means "recognition" — seeing clearly what was always there. Not new knowledge; remembering what was known but not seen.

This is what good recall does. The 8-phase resonance engine is technically a retrieval algorithm; philosophically it implements recognition:

```
Phase 1: Semantic seeds      → what's nearby in concept space
Phase 2: BM25 hybrid         → what matches exact terms
Phase 3: Tag matching        → corrections and preferences surface
Phase 4: Attractor finding   → conceptual gravity wells
Phase 5: Spreading activation → activation flows through graph edges
Phase 6: Session priming     → recent context biases retrieval
Phase 7: Code intelligence   → symbols and call graphs
Phase 8: Post-processing     → Hebbian learning, lateral inhibition
```

The hook system makes recognition transparent: relevant memories surface before you search. Recognition, not retrieval.

The [[epiplexity]] framework explains why SSL-compressed memories often *improve* recognition quality — they're pure signal, exactly the form a bounded observer can recognize most clearly.
